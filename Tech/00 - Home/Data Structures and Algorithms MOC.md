## Overview

Data structures and algorithms studies how to represent information and solve computational problems correctly and efficiently.

## Learning path

### Foundations

- [[Modeling the Problem]] — identify standard mathematical objects, constraints, and objectives before choosing an algorithm.
- [[Recursive Objects]] — recognize smaller objects of the same type and define decomposition rules and base cases.
- [[Algorithm Analysis and Big O Notation]] — compare growth rates, distinguish cases from bounds, and estimate scalability.

### Data structures

- [[Contiguous Versus Linked Data Structures]] — understand how memory representation shapes access, traversal, updates, and storage overhead.
- [[Arrays]] — use contiguous storage for direct indexed access, compact representation, and cache-friendly traversal.
- [[Pointers]] — distinguish an address, a pointer variable, and the value obtained by dereferencing it.
- [[Linked Lists]] — represent sequences as connected nodes and search them by following links from the head.


### Searching and lookup

- [[Binary Search Versus Hash Maps]] — choose between ordered search and hashed lookup based on the required operations and preprocessing costs.

### Sorting

- [[Sorting Algorithms]] — sorting methods with Python implementations and brief complexity analysis.
